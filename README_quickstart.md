# MAcordion Quick Start

# Requirements:
# - Python 3
# - pybooklid (for hinge angle):
#   - Install: `pip3 install pybooklid`
#
# Run:
# - `python3 accordion.py`
#
# Notes:
# - If hinge sensor is not available, it falls back to keyboard-only mode.
# - Latest releases are available on GitHub Releases.
# - Recent versions include fixes for lingering sound via deadzone, idle decay, and channel cleanup.
